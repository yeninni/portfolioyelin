# YELIN.zip

신예린의 픽셀 스타일 반응형 포트폴리오입니다. 제공된 `reference.png`의 흰 배경, 핑크 포인트, 캐릭터 배너와 콘텐츠 창 구성을 기준으로 구현했습니다.

## 실행

외부 라이브러리나 빌드 과정 없이 `index.html`을 브라우저에서 열 수 있습니다. 로컬 서버를 사용할 수도 있습니다.

```sh
cd /workspace/portfolioyelin
python3 -m http.server 8000
```

## GitHub Pages

이 저장소에 파일을 커밋·푸시한 뒤 GitHub **Settings → Pages → Deploy from a branch**에서 배포할 브랜치와 **/(root)** 를 선택합니다. 모든 이미지 경로는 상대 경로이므로 저장소 하위 주소에서도 동작합니다. 별도 빌드나 API 키가 필요하지 않습니다.

## 기능과 수정

- 6개 상위 탭, 하위 분류 필터, 3개 단위 페이지 이동, 카드와 상세 패널 연동
- 탭의 방향키·Home·End 이동, 버튼 키보드 조작, 선택 상태 및 포커스 표시
- 모바일 세로 배치, 스크롤 가능한 하위 분류, 작은 화면의 단일 열 카드
- `index.html`의 `sections`, `records`에서 분류와 실제 이력 데이터를 관리합니다.
- `projectEvidence`에서 제공된 사실에 근거한 역할·문제 해결·결과를 관리합니다. 미제공 성과 수치는 추가하지 않았습니다.
- `records`의 `image`, `detailImage` 값으로 프로젝트 이미지 경로를 분리했습니다. **현재 thumb-*.png 및 detail-rag.png는 시안에서 추출한 예시이며 실제 프로젝트 캡처가 아닙니다.** 화면에도 이를 표시했습니다. 채용용 공개 전 실제 결과물로 교체하세요.
- 연락처는 제공된 GitHub 저장소만 사용했습니다. 이메일이나 외부 프로젝트 URL은 임의 생성하지 않았습니다.

## 확인 결과

Chromium에서 1312px 데스크톱 화면과 제공 시안을 비교했습니다. 375·390·720·1312px에서 가로 넘침 없이 표시되며, 전체 탭·필터·상세 선택·페이지 이동·키보드 탭 이동을 확인했습니다. JavaScript 오류와 이미지 로딩 실패는 없었습니다. GitHub 게시 및 실제 Pages 주소 검증은 별도입니다.

## 원고 반영 (2026-10-23)

제공한 통합 원고를 기존 6개 탭에 반영했습니다. 프로젝트 14개, 소개·실무·활동 13개, 수상·선정 11개, 기술 9개, 학업·자격·발표 6개, 연락처 2개입니다. 프로젝트 상세 보기에서 문제·역할·과정·결과를 확인할 수 있습니다. 이메일 링크를 추가했습니다. 비공개 지원 현황과 전화번호는 제외했으며, 기록이 충돌하는 고용형태와 기간은 확정 표기를 보류했습니다.
